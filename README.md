# 🛒 Blinkit Sales Dashboard | Power BI

## 📌 Project Overview

The **Blinkit Sales Dashboard** is an interactive data visualization project built using Microsoft Power BI to analyze sales performance and outlet characteristics. The dashboard presents key performance indicators (KPIs) and multiple visualizations on a single page, providing a consolidated view of business performance.

The project focuses on analyzing sales based on outlet size, item type, fat content, outlet establishment year, outlet type, and outlet location.

## 🎯 Project Objectives

- Analyze overall sales performance using key business metrics.
- Evaluate outlet performance across different outlet sizes and locations.
- Understand sales distribution across various item types.
- Analyze sales based on the fat content of products.
- Explore sales trends according to outlet establishment year.
- Present business insights through an interactive, single-page dashboard.

## 📊 Key Performance Indicators (KPIs)

The dashboard includes four major KPIs:

- **Total Sales:** Represents the total revenue generated.
- **Average Sales:** Displays the average sales value.
- **Total Items:** Shows the total number of items sold or recorded.
- **Average Rating:** Represents the average customer rating.

## 📈 Dashboard Visualizations

### 1. Outlet Size Analysis
Analyzes outlet performance across different outlet sizes using four key metrics:
- Total Sales
- Average Sales
- Total Items
- Average Rating

### 2. Item Type Analysis
Visualizes sales performance across different item categories to understand the contribution of each item type to overall sales.

### 3. Fat Content Analysis
Evaluates product performance across different fat content categories using four key metrics:
- Total Sales
- Average Sales
- No. of Items
- Average Rating

### 4. Outlet Establishment Year Analysis
Displays sales trends based on the year outlets were established, helping identify changes in sales performance over time.

### 5. Outlet Type Analysis
Compares sales performance across different outlet types to understand their contribution to overall business performance.

### 6. Outlet Location Analysis
Analyzes sales distribution across different outlet locations to compare performance between location categories.

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – KPI calculations and measures.
- **Data Visualization** – KPI cards, charts, and comparative analysis.

## ✨ Key Features

- Single-page interactive dashboard.
- Four key performance indicator cards.
- Multiple visualizations for sales and outlet analysis.
- Comparative analysis using outlet size and fat content.
- Item category and location-based sales analysis.
- Clear and consolidated presentation of business metrics.

## 💡 Business Insights

The dashboard helps users explore:
- Which outlet sizes contribute most to total sales.
- How different item types perform in terms of sales.
- Differences in performance across fat content categories.
- How sales vary by outlet establishment year.
- Which outlet types and locations contribute to overall sales.
- How key metrics such as average sales, total items, and average rating vary across categories.
